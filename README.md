# Text Analysis — Консольный текстовый анализатор

Консольное приложение на C# для анализа текстовых данных. Загружает текст из файла или консоли, очищает от лишних символов, считает частотность слов, формирует топ-10 и рассчитывает лексическую статистику. На приложении отрабатываются различные уровни и методы тестирования.

## 🔍 Основные возможности

* Очистка текста: удаление пунктуации и цифр, приведение к нижнему регистру, сохранение дефисов и апострофов внутри слов
* Поддержка кириллицы и латиницы
* Четыре алгоритма сортировки: встроенная, пузырьком, Шелла, слиянием
* Расчёт статистики: общее количество слов, уникальных слов, процент уникальности
* Чтение входных данных и сохранение результатов в JSON-файл



## 🧪 Тестирование

* **Модульные тесты (xUnit):** написаны по подходу TDD с использованием 4 техник (BVA, ECP, Branch Coverage, Statement Coverage), применены параметризованные тесты и предположения
* **Тестирование поведения (BDD):** сценарии на языке Gherkin (Reqnroll) для очистки текста, подсчёта статистики и нагрузочных проверок сортировок
* **Нагрузочные эксперименты:** стресс-тесты сортировок на синтетических наборах данных разного размера и структуры (до 160 000 элементов)
* **Мутационное тестирование:** оценка качества тестов с помощью Stryker.NET

## 🛠️ Технологии

* C# / .NET 10
* xUnit + Xunit.Assume
* Reqnroll для BDD-сценариев
* Stryker.NET для мутационного тестирования
* Visual Studio 2026
